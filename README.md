# Kipui Community

A community hub for [Kipui](https://kipui.app) — report bugs, request features, ask questions, and share feedback.

## 💬 Get Help

Have a question about using Kipui?

Start a discussion and get help from the community.

- [Ask a Question](https://github.com/joypaul3592/kipui-community/discussions)

## 🐛 Report a Bug

Found something that isn't working as expected?

Before creating an issue, please make sure you're using the latest version of Kipui.

- [Report a Bug](https://github.com/joypaul3592/kipui-community/issues/new)

When reporting a bug, please include:

- Kipui version
- React / Next.js version
- Browser and OS
- Steps to reproduce
- Expected and actual behavior
- Relevant screenshots or reproduction links

## ✨ Request a Feature

Have an idea that could make Kipui better?

- [Request a Feature](https://github.com/joypaul3592/kipui-community/issues/new)

Please explain the problem you're trying to solve and how your proposed feature could help.
